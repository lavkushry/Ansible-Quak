## Guidelines
1. Ensure all tasks use FQCNs.
2. Provide default variables in `defaults/main.yml`.
3. Document required variables in `meta/main.yml` or `README.md`.
4. Include handlers in `handlers/main.yml`.
5. Organize tasks into logical files under `tasks/` and include them in `tasks/main.yml`.
